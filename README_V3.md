# Research Paper Intelligence V3
Stop Streamlit. Back up app.py, src and tests. Extract this ZIP into the existing inner Research_Paper_Summarizer_End_to_End folder, replacing matching files. Keep your existing .venv, sample_data and requirements.txt. In the existing activated PowerShell terminal run `python -m pytest -q` then `python -m streamlit run app.py`. No dependency reinstall is intended. Default mode is local Qwen, six evidence chunks. Test one PDF first, then multiple. Compare each claim with evidence and original tables. Use Evaluation with a manually authored reference to compute ROUGE. Printable HTML can be opened in a browser and printed to PDF. Source table detection may miss borderless tables; raw caption excerpts are also indexed, not verified structured tables. Basic checks flag missing page citations and unmatched numbers, not semantic contradictions. NeMo customization and TensorRT-LLM are not installed or validated; the existing compatible endpoint is retained for a separately deployed server. No accuracy or speed improvement is guaranteed without controlled evaluation. Tests cover chunk provenance, prompts, BM25, section exclusion and citation/number checks. Local GPU generation and Streamlit UI must be tested on your laptop.
